## 🚀 COMO USAR

### 1️⃣ INSTALAR
```bash
# Copiar módulo
cp -r finance_consulting /odoo/addons/

# Instalar via Odoo ou CLI
python odoo-bin -d seu_banco -i finance_consulting
```

### 2️⃣ CONFIGURAR
```
Ir para: Configurações > Usuários > Selecionar Usuário
Adicionar grupos:
  ✓ Consultoria Financeira / Consultor
  ✓ (Compliance, Gerente conforme perfil)
```

### 3️⃣ USAR
```
Menu: Consultoria Financeira > Clientes > Perfis Financeiros
Criar novo perfil com dados financeiros
Proceder com fluxo de onboarding
```

## 📈 FEATURES PRINCIPAIS

### Finance Profile
- Armazena dados financeiros completos
- Calcula poupança mensal automaticamente
- Histórico de evolução
- Integração com suitability
- Status (draft, active, paused, archived)

### Suitability
- Formulário completo CVM
- 3 perfis de risco
- Validação de experiência
- Conhecimento de produtos
- **Vencimento automático em 2 anos**
- Renovação com botão "Renovar"

### Investment Plan
- Alocação em 5 classes de ativos
- **Validação automática: total = 100%**
- Justificativa técnica
- Linhas detalhadas por ativo
- Estados: draft → pending → approved → active
- Rebalanceamento configurável

### Portfolio
- Acompanhamento de carteiras reais
- Múltiplas posições por carteira
- Cálculo de rentabilidade:
  - Consolidada
  - YTD (Year-to-Date)
  - Mensal
- **Identifica automaticamente carteiras que precisam rebalanceamento**
- Aportes e resgates rastreados

### Consulting Case (Dossiê)
- Checklist de onboarding (7 itens)
- Documentação integrada
- Propostas rastreáveis
- Reuniões registradas
- 5 estados de progresso
- Prioridades (baixa/média/alta/urgente)

## 🎯 FLUXOS IMPLEMENTADOS

### 1. Onboarding de Cliente
```
Novo Cliente
  ↓
Perfil (Draft) → Ativar
  ↓
Suitability → Aprovar
  ↓
Dossiê → Preencher Checklist
  ↓
Onboarding Completo
```

### 2. Planejamento
```
Perfil Ativo
  ↓
Plano (Draft) → Alocação 100%
  ↓
Submeter Aprovação → Aprovar
  ↓
Ativar → Carteira
  ↓
Posições → Pronto
```

### 3. Compliance
```
Suitability → Monitor 2 anos
  ↓
Auto-Expira → Alerta
  ↓
Renovar ou Criar Nova
```
